An end-to-end aerial image analysis system combining semantic segmentation with Retrieval-Augmented Generation (RAG) for interactive geospatial insights. Trained an 8-class SegFormer-B0 segmentation model on the UAVid dataset, integrated ChromaDB and Google Gemini 2.5 Flash for natural language querying, and implemented entropy-based uncertainty estimation.

An AI-powered clinical decision support system for early glaucoma detection, combining multimodal transfer learning (EfficientNetB0 and FundusQ-Net), image quality assessment, and predictive uncertainty estimation via Monte Carlo Dropout, with an interactive Streamlit dashboard for real-time prediction.
